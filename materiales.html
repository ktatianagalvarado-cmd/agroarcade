COMPONENTES Y MATERIALES

Materiales

Conoce los principales componentes y materiales utilizados para construir nuestros dos proyectos tecnológicos.

PROYECTO 01

🕹️ Arcade Game

Componentes utilizados para construir y controlar la garra robótica del Arcade Game.

01

Arduino

Controlador principal encargado de recibir las órdenes del joystick y coordinar los movimientos del sistema.

02

Joystick

Dispositivo utilizado por el visitante para controlar la dirección y movimiento de la garra.

03

PCA9685

Módulo utilizado para distribuir y controlar las señales destinadas a los seis servomotores.

04

Servomotores

Se utilizan seis servomotores para controlar las diferentes articulaciones y movimientos de la garra robótica.

05

Garra robótica

Mecanismo encargado de sujetar los objetos livianos y trasladarlos hasta la zona de entrega.

06

Fuente de alimentación

Proporciona la energía necesaria para alimentar los componentes del sistema sin depender directamente de la salida de 5 V del Arduino.

07

Estructura Arcade

Estructura tipo arcade que contiene el mecanismo, los objetos, el cableado y el área de control.

08

Interruptor general

Permite cortar la alimentación del sistema cuando sea necesario durante las pruebas o demostraciones.

PROYECTO 02

🤖 Palmabot Industrial

Componentes utilizados para construir la cinta transportadora y el sistema de detección y clasificación.

01

Arduino

Controlador que procesa la información recibida de los sensores y coordina las acciones del sistema.

02

Motorreductor de 12 V

Proporciona el movimiento necesario para hacer avanzar la banda transportadora.

03

Sensor FC-51

Sensor infrarrojo utilizado para detectar cuándo una muestra llega al área de análisis.

04

Sensor TCS3200

Sensor encargado de medir las intensidades de rojo, verde y azul para obtener los valores RGB.

05

Servomotor MG996R

Controla el movimiento de la compuerta encargada de dirigir la muestra hacia uno de los recipientes.

06

Cinta transportadora

Sistema mecánico encargado de transportar las muestras durante el proceso de clasificación.

07

Rodillos

Elementos mecánicos que permiten el desplazamiento de la banda transportadora.

08

Compuerta de clasificación

Mecanismo que dirige la muestra hacia el recipiente correspondiente según el criterio programado.
